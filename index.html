Software Development I (CSE-2340) • Mini Project 3-4

Total Marks: 14 (MP3: 7 Marks + MP4: 7 Marks) | Interactive API-Driven Web Application

1. DOM Manipulation & Dynamic Rendering (MP3) 4 / 4 Marks

Uses JavaScript DOM methods (querySelector, getElementById, createElement, innerHTML) to render API data dynamically. Implements interactive search, category pills, dual-view toggle (grid/list), and quick-view modal.

  • Product cards dynamically built and appended in js/ui.js (renderProducts)
  • Interactive category filter buttons dynamically built in js/ui.js (renderCategories)
  • Product quick-view modal with image gallery & customer reviews in renderQuickViewModal
  • Dynamic summary metrics dashboard rendered using DOM properties in renderStats
2. Event Handling & JavaScript Logic (MP3) 3 / 3 Marks

Employs addEventListener() across all user interactions and extensively uses arrays, objects, and higher-order array methods.

  • .map(): Used to transform data into category pills, gallery thumbnails, and review cards
  • .filter(): Multi-criteria filtering for search keywords, categories, price range, and ratings in js/app.js
  • .reduce(): Calculates order subtotal, VAT, average catalog price, top-rated product, and highest discount
  • .find() & .findIndex(): Locates specific product objects when adding to cart, opening modal, or toggling wishlist
  • .forEach(): Iterates and appends cards, attaches event listeners, and updates UI classes
  • addEventListener(): Handles input (debounced search), change (sort, slider, filters), click, keydown (/ search shortcut & Escape)
3. API Integration & Asynchronous Operations (MP4) 4 / 4 Marks

Retrieves external data from DummyJSON REST API using modern fetch() and async/await syntax. Fully implements Loading, Error, and Empty states.

  • Asynchronous service with async/await & try...catch...finally in js/api.js
  • Loading State: 8 shimmer skeleton cards displayed during network requests (renderSkeletons)
  • Error State: Interactive error alert card with "Retry Fetching" and offline fallback (renderError)
  • Empty State: Custom "No Products Found" graphic with a 1-click "Reset All Filters" button (renderEmpty)
4. Local Storage Persistence (MP4) 3 / 3 Marks

Implements 4 independent persistent features using localStorage that remain completely intact after page reloads.

  • Wishlist / Favorites: Persists favorited product IDs in shopnova_wishlist
  • Shopping Cart: Persists items and quantities in shopnova_cart
  • Dark / Light Theme: Persists user theme choice in shopnova_theme
  • Recent Searches: Persists recent search queries in shopnova_recent_searches
